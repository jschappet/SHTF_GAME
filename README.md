# Cultivating Resilience
Cultivating Resilience is a collaborative, real-world role-playing game where players solve evolving challenges, build community, share resources, and complete bounties. Each game builds on the knowledge, stories, and achievements of previous generations, creating a living, evolving civilization.

## Play your first game

Pick one of the [seven starter scenarios](scenarios/README.md). Each includes a read-aloud opening, starting supplies, a twist, and a bounty. Bring 3–8 people, paper, and pencils for a 45–75 minute tabletop session or walk-through.

## Live it in person

The [Field Edition](field-edition/README.md) is a self-run, self-funded camp lasting three to seven days. Build and test a phone charging station, a weather shelter, and a water filtration station, then hand the working projects to the next crew.
